# cn-patent-check — 中国专利查重与质量评估 Skill

适用于 [WorkBuddy](https://workbuddy.tencent.com/) / CodeBuddy 的用户级 skill：对国内专利申请材料执行**近似查重（查新）**、**名称与内容质量评分**，并按需生成**多个建议专利名**供撰写人选择。

## 功能

| 能力 | 说明 |
|---|---|
| 专利查重 | 抽取核心区别特征 → 三轮检索式（全特征 / 两两组合 / 上位 + IPC）→ Google Patents 检索与逐篇回验 → 特征比对表 |
| 查重风险等级 | 高 / 中 / 低三级，由 `scripts/score.py` 按特征覆盖计数自动判级，判级只采用已回验的对比文件 |
| 质量评分 | 百分制加权：名称 40（主题明确性 / 技术手段 / 区别特征 / 简洁性）+ 内容 60（技术问题 / 手段具体性 / 效果说服力 / 支持一致性 / 术语一致性），九维度 0–5 分锚点 |
| 建议专利名 | 按命名模板生成 3–5 个候选，机械初筛（字数 ≤25、营销词、主题类型词、型号代号）后交由用户选择 |
| 评估报告 | 输出 Markdown 报告（特征比对表、逐维度扣分理由、改进方向、待补充清单），含检索可靠性说明与免责声明 |

## 安装

**方式一：克隆到用户技能目录**（推荐，所有项目可用）

```bash
git clone https://github.com/lilan1177/cn-patent-check.git ~/.workbuddy/skills/cn-patent-check
```

**方式二：下载 zip 后导入** WorkBuddy 的 skill 安装入口。

安装后无需任何配置，新开对话即可使用。

## 使用

在对话中提供专利材料（名称 + 摘要，最好含权利要求书），并表达意图即可自动触发：

- “帮我查重这份专利：……”
- “评估一下这个专利的质量：……”
- “给几个建议专利名：……”
- “查重 + 评分 + 建议名称：专利名……内容……”（完整流程）

流程交互：先询问是否需要建议名称 →（需要则给候选让你选）→ 三轮检索 + 回验 → 评分 → 输出报告文件（`YYYY-MM-DD-patent-check-cn-<主题>.md`）。

## 重要边界（诚实声明）

1. **近似查新，非官方检索**：检索依赖 Google Patents 等公开渠道，国家知识产权局官方检索系统需登录无法直连。结论适合撰写阶段的内部自查；正式申请前应由代理机构或专业检索机构出具官方检索报告。
2. **强制回验机制**：来自文档分享站等非官方详情页的单一来源命中，必须经 Google Patents 详情页回验；回验失败的文件标记「未经核实」，不作为风险判级依据。
3. **材料缺失不脑补**：材料不全时对应评分维度记 0 并列入待补充清单，不凭空给分。
4. 本工具输出不构成法律意见。
